## How to run right now

- `npm install` — install all workspaces.
- `docker compose up -d` — start infrastructure and the hot-reload API/web containers.
- `npm run dev` — run API and web from the host after starting infrastructure with `docker compose -f docker-compose.yml up -d`.
- `npm run db:migrate` / `npm run db:rollback` — apply or roll back the latest tracked migration.
- `npm run db:seed` — apply the deterministic local demo seed; never use it on production data.
- `npm run db:check` — verify the configured PostgreSQL/PostGIS connection.
- `npm run test:integration` — run the disposable PostGIS/Redis/Mailpit integration suite (requires Docker daemon access).
- Web: `http://localhost:5173`; API health: `http://localhost:3000/health`; Mailpit: `http://localhost:8025`.
